# GitHub Setup

## Recommended repository name
`widyatama-website-performance-analysis`

## Repository description
End-to-end website performance and technical SEO analysis of 119 PMB Widyatama pages, from crawl diagnostics and root-cause analysis to remediation prioritization and dashboard reporting.

## Upload order
1. Upload the complete repository folder.
2. Commit with: `Portfolio release: analysis and dashboard`
3. Open **Settings → Pages**.
4. Source: `Deploy from a branch`
5. Branch: `main`
6. Folder: `/docs`
7. Save.
8. Add the GitHub Pages URL to the repository About section.
9. Add the repository URL to LinkedIn Featured / Projects.
