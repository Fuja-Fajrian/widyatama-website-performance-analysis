# Analysis Scripts

These scripts document the analysis pipeline used in the Widyatama website performance project.

## Main execution flow

| Order | Script | Role |
|---:|---|---|
| 0 | `test_pagespeed_api.py` | Validate the API key and a first PageSpeed request |
| 1 | `run_pagespeed_batch.py` | Collect PageSpeed results for the prepared URL/device input |
| 2 | `repair_pagespeed_csv.py` | Clean malformed/scientific metric values in the PageSpeed result CSV |
| 3 | `root_cause_batch_collector.py` | Run the main multi-page root-cause collection workflow |
| 4 | `repair_image_savings.py` | Re-read Lighthouse JSON and repair image-savings calculations without re-running tests |
| 5 | `template_root_cause_analysis.py` | Aggregate page-level diagnostics into template-level patterns |
| 6 | `template_remediation_priority.py` | Score and rank template remediation priorities |
| 7 | `repair_template_pattern_labels.py` | Correct pattern labels based on page count and consistency |
| 8 | `build_remediation_backlog.py` | Convert diagnostic findings into an actionable remediation backlog |
| 9 | `build_sprint1_evidence.py` | Build Sprint-1 evidence and pilot-page selection |
| 10 | `sprint1_deep_diagnostic.py` | Re-read existing Lighthouse JSON for pilot-level implementation evidence |

## Optional validation script

`root_cause_collector.py` is the earlier single-page / 3-run validation workflow used before scaling the root-cause process to the batch collector. It is kept because it documents the incremental analytical methodology.

## Python dependencies

Install:

```bash
python -m pip install -r requirements.txt
```

External Python packages:

- `requests`
- `python-dotenv`

The remaining imported modules are from the Python standard library.

## Lighthouse dependency

`root_cause_batch_collector.py` executes Lighthouse through `npx`.

You therefore need Node.js/npm available. A typical setup is:

```bash
node --version
npm --version
npx lighthouse --version
```

If Lighthouse is not installed, `npx` may ask to download it.

## API key

Copy:

```text
.env.example
```

to:

```text
.env
```

and set:

```text
PAGESPEED_API_KEY=your_key_here
```

Never commit `.env`. It is excluded by `.gitignore`.
