# LinkedIn Project Entry

## Title
Widyatama Website Performance & Technical SEO Analysis

## Associated role
Data Analyst / Web Performance Analysis Portfolio Project

## Description
Analyzed the public PMB Universitas Widyatama website through an end-to-end workflow covering website crawl, page-level performance diagnostics, PageSpeed/Core Web Vitals analysis, technical SEO, template/resource investigation, root-cause analysis, remediation prioritization, and dashboard reporting.

The project narrowed an initial crawl of 627 internal URLs into 119 internal HTML URLs for the primary audit, with 174 PageSpeed API observations, an 87-page baseline analysis, and 43 targeted smoke-tested pages.

The final portfolio deliverable is a decision-oriented dashboard and documented remediation strategy. Production implementation is intentionally outside the published project scope.
