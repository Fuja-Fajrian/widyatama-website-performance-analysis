# LinkedIn Upload Checklist

1. Upload `assets/linkedin-cover.png` as the visual cover.
2. Optionally add `assets/dashboard-overview.png` as a second image.
3. Copy the caption from `linkedin/linkedin-post.md`.
4. Replace placeholders with the GitHub repository URL and GitHub Pages dashboard URL.
5. Add the repository to LinkedIn **Featured**.
6. Add the project to the **Projects** section using `linkedin-project-entry.md`.

Before posting:
- verify the repository is public
- verify GitHub Pages opens correctly
- confirm no API keys or credentials exist in the repository
- confirm raw datasets contain no private or personal information
